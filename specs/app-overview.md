# Обзор приложения

## 1. Назначение

Игроки играют в расписной покер настоящими картами за столом. Приложение заменяет бумажный лист росписи: один человек («ведущий записи») вносит заказы и взятки, приложение считает очки, накопленный счёт и места.

## 2. Что приложение делает

- Создаёт игру на 3–6 игроков и само строит список раздач (число карт, раздающий, этап).
- Показывает всю игру одной таблицей: строки — раздачи, столбцы — игроки.
- Принимает заказы и взятки прямо в ячейках таблицы, с клавиатуры.
- Подсказывает порядок заказов и запрещённый заказ раздающего.
- Проверяет ввод: диапазон заказа, сумму заказов, сумму взяток.
- Считает очки за раздачу, накопленный счёт и места, включая игру «в тёмную».
- Позволяет исправить любую уже сыгранную раздачу с пересчётом итогов.
- Поддерживает отмену и повтор действий.
- Автоматически сохраняет игру и хранит историю партий.
- Позволяет завершить игру досрочно с фиксацией текущих мест.
- Помнит список постоянных игроков и показывает их статистику по сыгранным партиям.
- Экспортирует таблицу в файл.
- Меняет масштаб таблицы.

## 3. Чего приложение не делает

- **Не является игрой.** В нём нет карт, колоды, раздачи, ходов и взяток как игровых объектов.
- Не проверяет правила розыгрыша (масти, козырь, покер 7♠).
- Не определяет первого раздающего — его указывает пользователь.
- Не поддерживает сетевую игру, несколько устройств, учётные записи.
- Не имеет тёмной темы.

## 4. Платформа и условия использования

- Настольное приложение для **Windows 10/11**.
- Один пользователь, один компьютер; ноутбук стоит рядом со столом.
- Основной способ ввода — **клавиатура** (цифры, Enter, Tab, стрелки); мышь работает везде, но не обязательна.
- Работает без интернета, данные хранятся локально.
- Язык интерфейса — русский.

### Технология

Приложение пишется на **.NET MAUI**. Сейчас собирается и проверяется **только версия для Windows**, но устройство приложения не должно мешать позже добавить Android и iOS. Отсюда требования:

- Правила игры, подсчёт очков, проверки, отмена/повтор и статистика не зависят от интерфейса и от платформы.
- Общий код не обращается к возможностям Windows напрямую. Всё платформенное (папка с данными, диалог сохранения файла, горячие клавиши, размер окна) вынесено за отдельные точки расширения.
- Любое действие доступно указателем, а не только с клавиатуры: на телефоне клавиатуры и наведения мыши нет. Клавиши — ускорение, а не единственный путь.
- Экраны не привязаны к фиксированному размеру окна.

Что придётся сделать отдельно при переносе на телефон и сейчас не проектируется: ввод чисел касанием (выбор значения `0…K` вместо набора цифр) и вид таблицы на узком экране.

## 5. Основной сценарий

1. Пользователь запускает приложение и нажимает «Новая игра».
2. Выбирает игроков в порядке рассадки по часовой стрелке и указывает первого раздающего.
3. Открывается таблица, активна первая раздача.
4. На каждую раздачу: вносятся заказы → игроки играют за столом → вносятся взятки → строка закрывается, очки посчитаны, активной становится следующая раздача.
5. После последней раздачи приложение показывает победителя (победителей) и итоговые места.
6. Игра остаётся в истории, её можно открыть и экспортировать.

Дополнительные сценарии: продолжить незавершённую игру после перезапуска; исправить ошибку в старой раздаче; отменить последнее действие; завершить игру досрочно; посмотреть статистику игроков.

## 6. Термины

| Термин | Значение |
|--------|----------|
| Игра (партия) | Полная последовательность раздач от первой до последней |
| Раздача | Одна строка таблицы: K карт, раздающий, заказы, взятки, очки |
| N | Число игроков, 3–6 |
| M | Максимум карт на руках, `floor(36 / N)` |
| K | Число карт у игрока в раздаче |
| Заказ (З) | Сколько взяток игрок обещает взять, `0…K` |
| Пас | Заказ 0 |
| Взятки (В) | Сколько взяток игрок фактически взял |
| В тёмную | Заказ до раздачи карт; очки игрока за раздачу ×2 |
| Запрещённый заказ | Число, которое раздающий не может заказать, чтобы сумма заказов не равнялась K |
| Финальное плато | Последние N раздач по M карт, все играют в тёмную |
| Активная раздача | Первая незакрытая раздача, в которую сейчас идёт ввод |
| Закрытая раздача | Раздача, где введены все заказы и взятки и пройдены проверки |
| Досрочное завершение | Окончание игры до последней раздачи; места определяются по закрытым раздачам |
