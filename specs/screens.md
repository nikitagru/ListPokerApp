# Экраны и навигация

Приложение — одно окно. В нём сменяются экраны; диалоги открываются поверх текущего экрана.

```
                ┌──────────────────┐
     запуск ──▶ │ Стартовый экран  │◀─────────────────┐
                └──┬─────┬─────┬───┘                  │
        Новая игра │     │     │ Игроки               │ «К списку игр»
                   ▼     │     ▼                      │
        ┌──────────────┐ │  ┌──────────────┐          │
        │ Новая игра   │ │  │ Игроки       │          │
        └──────┬───────┘ │  └──────────────┘          │
       Начать  │         │ открыть игру из списка     │
               ▼         ▼                            │
        ┌──────────────────────────┐                  │
        │ Таблица игры             │──────────────────┘
        └──────────────────────────┘
```

Минимальный размер окна — 1024×640. Размер и положение окна запоминаются.

Со стартового экрана и из таблицы игры кнопка «Игроки» ведёт к списку постоянных игроков и их статистике.

---

## 1. Стартовый экран

Показывается при запуске.

- Кнопка **«Новая игра»**.
- Кнопка **«Продолжить»** — открывает последнюю незавершённую игру. Скрыта, если таких нет.
- Кнопка **«Игроки»** — список постоянных игроков и статистика.
- **Список игр** — все сохранённые партии, новые сверху.

Строка списка игр:

| Поле | Пример |
|------|--------|
| Дата начала | 12.10.2026 19:40 |
| Игроки | Аня, Боря, Вика |
| Состояние | «Раздача 7 из 28», «Завершена» или «Завершена досрочно (12 из 28)» |
| Результат | для завершённой, в том числе досрочно, — победитель(и) и счёт: «Вика — 214» |

Действия со строкой: **открыть** (двойной щелчок / Enter), **удалить** (с подтверждением).

Незавершённых игр может быть несколько.

---

## 2. Новая игра

Форма из двух частей.

### Игроки

- Список мест от 1 до 6, заполнено минимум 3.
- Порядок мест = **порядок рассадки по часовой стрелке**: следующий в списке сидит слева от предыдущего.
- В каждое место имя либо выбирается из списка постоянных игроков (выпадающий список с поиском), либо вводится новое. Новое имя автоматически добавляется в список постоянных игроков.
- Места можно менять местами (перетаскиванием или кнопками ▲▼) и удалять.
- Имена в одной игре не повторяются. Длина имени — от 1 до 20 символов.

### Первый раздающий

- Выбор одного из введённых игроков (переключатель рядом с именем).
- По умолчанию не выбран — пользователь обязан указать его явно: раздающий определяется за столом открытой раздачей до туза.

### Сводка и запуск

Под формой показывается сводка: «3 игрока · максимум 12 карт · 28 раздач».

Кнопка **«Начать»** активна, когда игроков 3–6, имена корректны и выбран первый раздающий. После нажатия состав игроков и первый раздающий **не меняются** до конца игры.

Кнопка «Отмена» возвращает на стартовый экран.

## 4. Игроки

Список постоянных игроков в виде таблицы со статистикой.

### Управление списком

- Добавить, переименовать, удалить.
- Имена уникальны (без учёта регистра).
- Удаление и переименование **не влияют на уже созданные игры**: игра хранит собственные копии имён.
- Переименование сохраняет статистику игрока. Удаление убирает игрока из статистики; его партии остаются в списке игр.

### Статистика

Одна строка на игрока, сортировка щелчком по заголовку столбца (по умолчанию — по числу побед).

**Разбивка по числу игроков.** Над таблицей — переключатель: **Все · 3 · 4 · 5 · 6**. Он отбирает игры, по которым считается статистика: все завершённые либо только партии на указанное число игроков. Варианты, для которых нет ни одной завершённой игры, недоступны. Выбор запоминается.

| Столбец | Как считается | В режиме «Все» |
|---------|---------------|:--------------:|
| Игр | Число завершённых игр с участием игрока | да |
| Побед | Число игр, где игрок занял 1-е место; при ничьей победа засчитывается каждому лидеру | да |
| % побед | Победы / игры | да |
| Точность заказов | Доля раздач, где взято ровно столько, сколько заказано (включая выполненный пас) | да |
| В тёмную | Число добровольных заказов в тёмную (финальное плато не считается) | да |
| Среднее место | Среднее по занятым местам | нет |
| Средний счёт | Средний итоговый счёт | нет |
| Лучший / худший счёт | Максимальный и минимальный итоговый счёт | нет |

Место и счёт зависят от числа игроков и числа раздач, поэтому усреднять их по партиям разного состава бессмысленно: в режиме «Все» эти столбцы скрыты и показываются только при выборе конкретного числа игроков.

Игроки, не сыгравшие ни одной завершённой партии выбранного состава, показаны с прочерками в конце списка.

Правила учёта:

- Учитываются только **завершённые** игры, включая завершённые досрочно. Идущие игры в статистику не входят.
- У досрочно завершённой игры учитываются только закрытые раздачи.
- Удалённая игра перестаёт учитываться.
- Игрок без завершённых игр показан с прочерками.
- Статистика нигде не хранится: она каждый раз считается по сохранённым играм, поэтому правка старой партии сразу в ней отражается.

Щелчок по строке игрока открывает список его игр: дата, соперники, место, счёт; из него можно открыть партию. Список учитывает выбранную разбивку по числу игроков.

---

## 5. Диалоги

| Диалог | Когда | Кнопки |
|--------|-------|--------|
| Удаление игры | «Удалить» в списке игр | Удалить / Отмена |
| Удаление игрока | «Удалить» в списке игроков | Удалить / Отмена |
| Итоги игры | Закрыта последняя раздача или игра завершена досрочно | Закрыть / Экспорт / К списку игр |
| Досрочное завершение | «Завершить игру» в таблице | Завершить / Отмена |
| Экспорт | Кнопка «Экспорт» в таблице | Выбор формата и файла |

Выход из таблицы игры подтверждения не требует: всё сохранено автоматически.
