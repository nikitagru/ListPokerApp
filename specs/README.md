## Порядок работы

Документация пишется итеративно. Описано **что** делает приложение, **как оно выглядит** и **как устроено** (.NET MAUI, сейчас только Windows). Следующий шаг — реализация по плану из [architecture.md](architecture.md#10-план-реализации).

При расхождении правил подсчёта между документами верным считается [gamerules.md](gamerules.md).
