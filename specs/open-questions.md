# Решения, допущения и открытые вопросы

## 1. Принятые решения

| Вопрос | Решение |
|--------|---------|
| Вид таблицы | Классический лист: строки — раздачи, столбцы — игроки, подстолбцы З / В / Оч / Счёт |
| Способ ввода | Прямо в ячейках таблицы, с клавиатуры |
| Сохранение | Автосохранение и история всех игр |
| Дополнительно | Отмена/повтор, экспорт, список постоянных игроков |
| График счёта | Не делаем |
| Технология | .NET MAUI. Сейчас только Windows; устройство приложения не должно мешать добавить Android и iOS |
| Выход посреди раздачи | Частично введённая раздача сохраняется как есть, этого достаточно |
| Досрочное завершение | Нужно; места фиксируются по закрытым раздачам |
| Тёмная тема | Не нужна |
| Масштаб таблицы | Делаем |
| Статистика игроков | Нужна, с разбивкой по числу игроков: Все · 3 · 4 · 5 · 6 |
| Отрисовка таблицы | Свой рендер через `Microsoft.Maui.Graphics`; один код рисует экран и PNG |
| Проекты | `ListPoker.Core` (логика без MAUI) + `ListPokerApp` (интерфейс) + `ListPoker.Core.Tests` |

### Согласованные правила поведения

1. **Заказ раздающего в финальном плато.** В финале все играют в тёмную, но порядок заказов обычный: раздающий заказывает последним, запрет на `Σ заказов = K` действует.
2. **Порядок заказов — подсказка, а не блокировка.** Заказ любого игрока, кроме раздающего, можно ввести вне очереди. Раздающий — строго последним.
3. **Последняя взятка подставляется автоматически** как остаток до K и требует подтверждения `Enter`.
4. **Первого раздающего указывает пользователь.** Кнопки «выбрать случайно» нет.
5. **Состав игроков и рассадка не меняются** после начала игры.
6. **Завершённую игру можно править** так же, как идущую.
7. **Незавершённых игр может быть несколько.**
8. **История отмены не сохраняется** между запусками приложения.
9. **Экспорт: CSV и PNG.** Печати и PDF нет.
10. **Интерфейс только на русском**, одна светлая тема.

11. **Досрочно завершённую игру можно возобновить** и доиграть.
12. **Досрочное завершение доступно после первой закрытой раздачи.** Игру без единой закрытой раздачи можно только удалить.
13. **Досрочно завершённые игры входят в статистику** наравне с доигранными, хотя счёт в них меньше — это занижает «средний счёт».
14. **Набор показателей статистики:** игры, победы, % побед, среднее место, средний счёт, лучший и худший счёт, точность заказов, число заказов в тёмную.
15. **При ничьей победа засчитывается каждому лидеру.**
16. **Удаление игрока убирает его из статистики**, восстановить её нельзя.
17. **Масштаб: 75–200% с шагом 25%**, один на всё приложение, действует только на таблицу игры.
18. **В режиме «Все» скрыты среднее место, средний, лучший и худший счёт.** Они показываются только при выборе конкретного числа игроков, потому что между партиями разного состава несравнимы. Игры, победы, % побед, точность заказов и число заказов в тёмную видны всегда.
19. **Пока строка на правке, отмена/повтор и досрочное завершение недоступны.** Сначала правку нужно применить или отменить.
20. **Глубина истории отмены — 500 действий.** С запасом на целую партию.
21. **Нечитаемый файл игры пропускается** при загрузке и не перезаписывается; приложение сообщает, сколько игр не удалось прочитать.
